# 程式碼模式庫

收集專案中證明有效的程式碼片段和設計模式，便於重複使用。

## 📂 分類

### React 元件模式
- 狀態管理模式
- Hook 使用模式
- 錯誤邊界處理

### API 整合模式
- HTTP 客戶端設定
- 錯誤處理模式
- 資料格式轉換

### 後端服務模式
- FastAPI 路由組織
- 異步處理模式
- 設定管理模式

## 🔍 如何使用

1. 當您寫出特別滿意的程式碼時，複製到對應分類的檔案中
2. 附上簡短的說明和使用情境
3. 包含基本的使用範例

## 📝 記錄格式

建議每個模式使用以下格式：

```markdown
## 模式名稱

**使用情境**: 簡述何時使用此模式

**程式碼**:
```
// 程式碼範例
```

**說明**: 關鍵概念解釋

**相關檔案**: 專案中的實際使用位置
```
