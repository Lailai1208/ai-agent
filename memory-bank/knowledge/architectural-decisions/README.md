# 架構決策記錄 (ADR)

記錄專案中的重要技術決策，以便日後回顧和新成員理解設計原因。

## 決策記錄格式

每個決策建議使用以下格式命名：`YYYY-MM-DD-決策主題.md`

### 建議的決策記錄模板

```markdown
# ADR-001: [決策標題]

**日期**: YYYY-MM-DD
**狀態**: [提議中/已接受/已拒絕/已廢棄]

## 背景
簡述需要做決策的情況或問題。

## 選項
列出考慮過的方案。

## 決策
最終選擇的方案及原因。

## 後果
這個決策帶來的正面與負面影響。
```
