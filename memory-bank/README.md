# Memory Bank - AI Agent 專案知識庫

這是專為快速迭代而設計的專案記憶庫，用於記錄開發過程中的知識、決策和經驗。

## 📁 結構說明

### `knowledge/` - 共享知識庫
穩定的、經過驗證的知識，可以反覆參考使用：
- `architectural-decisions/` - 重要的技術決策紀錄
- `code-patterns/` - 可重用的程式碼片段和模式
- `setup-notes/` - 環境設定的關鍵筆記

### `logs/` - 開發日誌
動態更新的過程記錄：
- `decisions.md` - 快速決策日誌
- `experiments/` - 實驗記錄資料夾
- `failure-analysis.md` - 失敗分析與解決方案

### `tasks/` - 任務管理
專案任務的組織與追蹤：
- `current-sprint.md` - 當前衝刺任務清單
- `backlog.md` - 未來計劃的功能
- `ideas.md` - 靈感與想法記錄

## 🚀 快速開始

1. **記錄決策**: 當您做出重要技術選擇時，在 `knowledge/architectural-decisions/` 新增記錄
2. **保存解決方案**: 遇到問題並解決後，更新 `logs/failure-analysis.md`
3. **管理任務**: 使用 `tasks/current-sprint.md` 追蹤當前工作

## 📝 使用原則

- **輕量記錄**: 簡短、實用的記錄即可
- **持續更新**: 隨開發過程動態維護
- **易於查找**: 使用清晰的檔案命名和結構
