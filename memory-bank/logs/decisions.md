## 記錄格式

```
**日期**: YYYY-MM-DD
**決策**: 簡短描述決策內容
**原因**: 為什麼做這個決策
**影響**: 這個決策的預期影響
---
```

## 決策記錄

**日期**: 2025-01-30
**決策**: 前端使用 TanStack Query 管理伺服器狀態
**原因**: 需要自動處理 API 快取、重新獲取和錯誤重試
**影響**: 減少手動狀態管理的複雜度，提升用戶體驗
---

**日期**: 2025-01-30
**決策**: 後端使用 uv 作為 Python 套件管理工具
**原因**: uv 比 pip 更快，且與 requirements.txt 相容
**影響**: 加快依賴安裝速度，特別是在 CI/CD 環境中
---

**日期**: 2025-01-30
**決策**: 採用 Feature-based 的元件資料夾結構
**原因**: 比起按類型分類，按功能分類更容易維護和找到相關程式碼
**影響**: 新功能開發時程式碼更集中，便於模組化
